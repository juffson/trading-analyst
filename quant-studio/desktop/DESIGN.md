# Quant Lab 桌面界面设计

## 布局

- **左侧工作区导航（228 px）**：品牌、当前因子库、Web 工作台各模块入口、数据来源提示。
- **中间因子列表（380 px）**：搜索框、方向筛选、实现状态筛选、结果数量和可滚动卡片。
- **右侧因子档案（自适应）**：名称与状态、回测入口、配对关系、参数和信号逻辑。
- 顶部用四个数字快速呈现总数、已实现、配对组合与待实现数量。

## 视觉规则

- 深蓝黑背景 `#0b111b`，卡片 `#141f2e`，边框 `#29394c`。
- GPUI Kit 组件统一使用暗色主题，使输入框和按钮与工作台保持一致。
- 浅绿 `#b8ee80` 表示做多与已实现；浅蓝 `#83c4fb` 表示做空与配对组合；琥珀色 `#f4c982` 表示待实现。
- 中文为主、英文眉题为辅，层级依次是页面标题、功能标题、说明、辅助标签。

## 交互

- 搜索同时匹配名称、ID、说明；方向和实现状态筛选可叠加。
- 筛选无结果时显示空状态；选中卡片后右侧显示完整参数与逻辑。
- 查看配对因子会切回全部方向、关闭实现状态筛选，并将搜索定位到配对项。
- 已实现因子可带着选择跳到 Web 回测页；其他模块入口直达对应 Web 页面。
- 刷新会重新读取仓库内的因子库，并保留仍存在的选中项。

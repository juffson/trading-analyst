# Quant Lab 桌面版

桌面版使用 GPUI Kit 0.8.1。界面采用深色研究工作台布局：左侧模块入口、中间因子列表、
右侧因子详情。列表支持名称 / ID / 说明检索、做多 / 做空筛选、仅看已实现；详情展示
配对关系、参数与信号逻辑。数据直接读取
`auto-trader/strategy-kit/strategy_kit.json`，与现有服务共用同一份因子模型和数据。
已实现的因子可从详情直接进入窗口内的回测页，回测页会预选该因子或配对组合。

```bash
cd quant-studio
cargo run --manifest-path desktop/Cargo.toml
```

需要 Rust 和对应平台的 GPUI 编译依赖。首次构建会下载图形框架依赖。当前桌面程序从构建时的
源码目录定位因子库，因此仍需保留此仓库；独立应用打包和数据路径配置尚未实现。

左侧的回测、模拟交易、实盘查询、公司分析和交易记录分析入口会在同一窗口内打开，
并保留桌面导航。这些页面通过内嵌 WebView 复用现有 Web 业务功能和图表，不会跳到外部浏览器。
桌面程序会在需要时自动启动本地服务；如果服务已在 `127.0.0.1:4870` 运行，则直接复用。
左侧「账号设置」可更新 Longbridge OpenAPI 凭据；应用内保存的值会立即用于回测和实盘查询。
若 `127.0.0.1:4870` 上已有旧版服务，需先重启该服务才能看到新设置入口。
后续若逐页改为 GPUI 原生界面，需保持现有业务能力和数据格式。
